# Proxy Key Checker

Proxy Key Checker — это лёгкий Python-скрипт для проверки прокси-ключей и сортировки их по доступности и задержке соединения (latency).

Проект предназначен для быстрого отбора рабочих ключей без сторонних зависимостей и сложной настройки.

---

## Поддерживаемые протоколы

* VLESS
* VMess
* Shadowsocks (SS)
* Trojan

---

## Возможности

* Загрузка ключей из `.txt` файлов
* Автоматическое удаление дубликатов
* Проверка доступности хоста и порта
* Измерение задержки соединения
* Классификация качества (good / normal / weak)
* Сортировка рабочих ключей по минимальному пингу
* Генерация файла с результатами
* Подробный лог выполнения

---

## Требования

* Python 3.8+
* Только стандартная библиотека Python

---

## Установка

```bash
git clone https://github.com/USERNAME/proxy-key-checker.git
cd proxy-key-checker
```

---

## Настройка

В файле скрипта укажите свои каталоги:

```python
KEYS_FOLDER = r"PATH_TO_KEYS_FOLDER"
NEW_KEYS_FOLDER = r"PATH_TO_OUTPUT_FOLDER"
```

* `KEYS_FOLDER` — папка с `.txt` файлами, содержащими ключи
* `NEW_KEYS_FOLDER` — папка для результатов и логов

---

## Использование

```bash
python checker.py
```

После выполнения в папке вывода будут созданы:

* файл с рабочими ключами, отсортированными по задержке
* лог проверки

---

## Формат результата

```
<latency>ms | <quality> | <protocol> | <host>:<port> | <full_key>
```

Пример:

```
82ms | good | VLESS | example.com:443 | vless://...
```

---

## Ограничения

* Проверяется только сетевое соединение (host:port)
* Не проверяется корректность шифрования и авторизации
* Результаты зависят от текущих сетевых условий
